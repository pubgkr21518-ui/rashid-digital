IP Information

IP Information is an educational project designed to demonstrate how basic public IP information can be retrieved and displayed.

Features

  • Basic public IP information
  • Network-related information
  • Simple command-line interface
  • Python implementation
  • Designed for learning

Installation

git clone YOUR-REPOSITORY
cd ip-information
python3 ip-information.py

Usage

Run the Python program from your terminal. The program retrieves basic information associated with the public IP connection. 

python3 ip-information.py

Source Code

import urllib.request
import json

url = "https://ipinfo.io/json"

try:
    with urllib.request.urlopen(url, timeout=10) as response:
        data = json.loads(
            response.read().decode()
        )

    print("IP Information")
    print("----------------")
    print("IP:", data.get("ip", "N/A"))
    print("City:", data.get("city", "N/A"))
    print("Region:", data.get("region", "N/A"))
    print("Country:", data.get("country", "N/A"))
    print("Organization:", data.get("org", "N/A"))

except Exception as error:
    print("Unable to retrieve information.")
    print("Error:", error)

How It Works

The Python program requests basic public-IP information and displays the returned data. It is intended for learning about APIs, HTTP requests and network information.
