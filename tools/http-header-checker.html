IPFindX

IPFindX is a command-line IP intelligence project designed for cybersecurity learning, network administration and authorized research.

Features

  • Single public IP lookup
  • Batch IP processing
  • Geolocation information
  • ISP and organization information
  • ASN information
  • Proxy, mobile and hosting indicators
  • Reverse DNS information
  • Structured output

Installation

pip install ipfindx

Or install from the source repository:

git clone https://github.com/VritraSecz/IPFindX.git
cd IPFindX
pip install -r requirements.txt

Usage

ipfindx -i 8.8.8.8

Batch processing:

ipfindx -l ip_list.txt

Help:

ipfindx --help
