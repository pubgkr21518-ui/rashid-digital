IP Information

Educational IP information and networking tool hosted directly inside Rashid CyberForge.

Features

  • Public IP information
  • Approximate geographic information
  • ISP / organization information
  • ASN information when available
  • Reverse DNS information
  • Private and reserved IP awareness

Installation

git clone https://github.com/VritraSecz/IPFindX.git
cd IPFindX
pip install -r requirements.txt

Usage

ipfindx -i 8.8.8.8

ipfindx --help

Use IP information tools only for systems and addresses you are authorized to investigate.
